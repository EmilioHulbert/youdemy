when using robocopy in windows how do i exclude c:\users\kibet\crossdevice from being copied
To exclude a specific folder from being copied in Robocopy, use the /XD (Exclude Directories) option.
Here is the exact syntax you need:
cmd
robocopy "C:\source" "D:\destination" /E /XD "C:\users\kibet\crossdevice"
Use code with caution.
Key Elements:
/XD "C:\users\kibet\crossdevice" – Tells Robocopy to skip this specific directory path completely. Always wrap the path in quotation marks to prevent errors caused by spaces or special characters.
/E – Copies all subdirectories, including empty ones (a standard flag used for full backups).
Pro-Tips for Exclusions:
Multiple Folders: You can exclude multiple folders by separating them with a space:
/XD "C:\path\folder1" "C:\path\folder2"
Relative Paths: If your source folder is C:\users\kibet, you can just use the folder name instead of the absolute path:
/XD crossdevice

To rebuild your system's boot configuration and fix the missing boot entries via the Command Prompt, we need to address a quick technical detail first: Modern laptops running Windows 11 use GPT/UEFI (BCDBoot) instead of the legacy MBR.
If you try to run traditional legacy MBR commands (bootrec /fixmbr) on a modern Lenovo setup, you will likely get an "Access is denied" error because your system boots via UEFI.
Instead, we will use the BCDBoot tool to completely wipe and recreate your boot configuration files inside that 100MB partition. Here is exactly how to do it using CMD from your Windows 10 installation media:
Step 1: Open Command Prompt at Boot
Boot from your Windows 10 installation USB.
On the very first language screen, press Shift + F10 on your keyboard. This will instantly open a black Command Prompt window.
Step 2: Identify Your Drive Letters
Because you are booting from a USB, the drive letters might be shifted (e.g., your Windows 10 OS partition might look like D: or E: instead of C:). Let's find out exactly what they are:
Type diskpart and press Enter.
Type list volume and press Enter.
Look at the list and identify two crucial things:
The 100MB System Partition: This is usually formatted as FAT32 (labeled System or Hidden). Look at its letter (if it doesn't have one, we will fix that next).
Your Main Windows 10 Partition: Look for your large NTFS partition where Windows 10 is actually installed. Note its drive letter (for this guide, let's assume it is C:).
Step 3: Assign a Letter to the 100MB Partition (If Hidden)
If your 100MB FAT32 partition does not have a letter assigned to it in the list, assign it one manually:
Type select volume X (replace X with the volume number of your 100MB FAT32 partition) and press Enter.
Type assign letter=V and press Enter.
Type exit and press Enter to leave Diskpart.
Step 4: Rebuild the Boot Files (The Fix)
Now, run the following command to completely rewrite the boot configuration from your Windows 10 system files straight into your 100MB partition:
cmd
bcdboot C:\Windows /s V: /f UEFI
Use code with caution.
(Make sure to replace C: with your actual Windows OS partition letter from Step 2, and V: with the letter assigned to your 100MB partition).
What this command does:
C:\Windows – Points to your working Windows installation to grab clean boot files.
/s V: – Copies those brand-new boot files directly into your 100MB system partition.
/f UEFI – Forces the system to build modern UEFI boot entries, bypassing the outdated, locked MBR structure and cleaning out the ghost Windows 11 remnants.
Once you see the message "Boot files successfully created," close the command prompt, unplug your USB drive, and restart your Lenovo laptop. It should boot straight into Windows 10 without any issues.

cmd

Use code with caution.
