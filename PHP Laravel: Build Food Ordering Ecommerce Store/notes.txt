sudo apt update

2️⃣ Verify the extension is enabled

Run:

php -m | grep -i sqlite

You must see:

pdo_sqlite
sqlite3

3️⃣ Restart your PHP service (important)

If using Laravel’s built-in server only:

# usually not needed, but safe
php artisan serve


If you’re using Apache:

sudo systemctl restart apache2


If using PHP-FPM:

sudo systemctl restart php8.2-fpm

4️⃣ Re-run migrations cleanly

From your Laravel project root:

php artisan migrate:fresh

No “could not find driver”

Tables created successfully
