The Culprit: Windows.old
Windows has likely archived your entire previous Evaluation OS into a folder called C:\Windows.old. This folder usually takes up 15GB to 25GB. It’s kept there for 10 days so you can "roll back," but since you wanted to get rid of the Evaluation version anyway, you don't need it.

How to Reclaim Your Space (The Guru Way)
Don't just shift-delete the folder; Windows protects it with specific permissions. Use the built-in cleanup tools to nukes it properly.

1. The Storage Settings Method (Easiest)
Go to Settings > System > Storage.

Click on Temporary files.

Look for "Previous Windows installation(s)".

Check that box (and "Windows Update Cleanup" if it's there).

Click Remove files.

2. The PowerShell Method (Fastest)
Since you’re comfortable in the CLI, run this as Administrator to trigger the cleanup manager's "Deep Clean" mode:

PowerShell
cleanmgr /sageset:65535
# Check 'Previous Windows installation(s)' and 'Temporary Setup Files' in the window that pops up.

cleanmgr /sagerun:65535
3. Hidden Installer Cache
The ISO mount and the setup.exe process also dump files in C:\$Windows.~BT. This is a hidden system folder. If it's still there after the cleanup, you can delete it manually or let cleanmgr handle it.
